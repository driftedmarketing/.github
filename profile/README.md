# Drifted Marketing

How work moves here, in four lines.

1. Nobody pushes to `main`. Not people, not agents. It is locked.
2. Work happens on your own branch, named `you/what-it-is`, and becomes a pull request.
3. Every push and every pull request announces itself to the team. Read it, do not reply to it.
4. Umer reads the pull request and either merges it or closes it. That is the approval.

Plans and briefs are work too. A plan on a branch is a pull request like any other.
